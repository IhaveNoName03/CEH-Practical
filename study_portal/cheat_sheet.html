Common Exam Workflows (step-by-step)

1. Web App Pentest: gobuster dir -u URL -w wordlist → nikto -h URL → sqlmap -u "URL?param=1" --dbs → sqlmap -D dbname --tables → sqlmap -T table --dump. Answer: usernames/passwords or count.

2. Password Cracking: Identify hash type (hashid/hash-identifier) → john --format=FORMAT --wordlist=rockyou.txt hash.txt → or hashcat -m MODE -a 0 hash.txt rockyou.txt. Answer: plaintext password.

3. WiFi Cracking: airmon-ng start wlan0 → airodump-ng wlan0mon → airodump-ng -c CH --bssid BSSID -w capture wlan0mon → (wait for handshake) → aircrack-ng -w rockyou.txt capture*.cap. Answer: password + length.

4. Steganography: steghide info image.jpg (check if data embedded) → steghide extract -sf image.jpg -p password → or stegseek image.jpg rockyou.txt. Answer: extracted text/file.

5. PCAP Analysis: tshark -r file.pcap -Y "filter" -T fields -e field → or wireshark GUI. Common: http.request, dns, tcp.flags.syn==1, arp. Answer: IP, count, protocol, or topic.

6. Privilege Escalation (Linux): sudo -l → find / -perm -4000 2>/dev/null → cat /etc/crontab → linpeas.sh. Answer: contents of /root/flag.txt or root password.

7. SMB Enumeration: enum4linux -a IP → smbclient -L //IP → smbmap -H IP. Answer: share names, user list, or file count.

8. Metasploit Exploitation: msfconsole → search exploit → use exploit/path → set RHOSTS IP → set payload → exploit → (meterpreter) ls / cat / download. Answer: file content or count.

9. RDP/SSH Brute Force: hydra -l user -P rockyou.txt rdp://IP or ssh://IP. Answer: cracked password.

10. Binary Analysis: file binary → readelf -l binary | grep LOAD → strings binary | grep -i flag. Answer: segment size or extracted string.

How to use this cheat sheet

  1. Find the tool for your current task using the module sections or search (Ctrl+F).
  2. Copy the command block — commands are in <pre> blocks. Blue-highlighted steps below each block explain what to do.
  3. Replace placeholders like 10.10.1.13, target.com, admin with your exam values.
  4. Check the answer format — some questions want an IP, a count, a hash, or a password. Read the question carefully.
  5. If stuck 20+ min, skip and move on. Return at the end.
