CEH Practical Exam — Day Of

Exam Day Checklist

Run through this checklist the morning of the exam. Check off each item as you go. Progress saves in your browser.

1. Verify VM boots

Start ParrotSec/Kali VM. Confirm network adapter is in NAT or Bridged mode as required. Test internet connectivity: ping 8.8.8.8

2. Verify tools are installed

Run: nmap --version; sqlmap --version; hydra -h 2>&1 | head -1; metasploit-framework; wireshark --version; aircrack-ng --help 2>&1 | head -1; john --version; hashcat --version

3. Verify wordlists exist

Check: ls /usr/share/wordlists/rockyou.txt; ls ~/ctf/wordlists/SecLists 2>/dev/null || ls /usr/share/seclists 2>/dev/null. If missing, download: wget https://github.com/danielmiessler/SecLists/archive/master.zip

4. Verify browser & Burp Suite

Open Firefox/Chromium. Verify Burp Suite launches and proxy is configured (127.0.0.1:8080). Test: browse to any site with proxy on.

5. Verify Python & pip tools

Run: python3 -c "import requests, bs4, scapy; print('OK')"; pip3 list | grep -i -E 'scapy|requests|beautifulsoup'

6. Verify network connectivity to exam subnet

Ping the exam gateway: ping 10.10.10.1 (adjust to your exam subnet). Verify you can reach target IPs.

7. Open this study portal

Keep the study portal open in a browser tab for quick reference. Bookmark: cheat_sheet.html, practice.html, module_13 (web), module_12 (system hacking).

8. Note-taking setup

Open a text editor (nano/vim/gedit) for recording answers. Create a file: ~/exam_notes.txt. Format: Q1: answer | Q2: answer | ...

9. Screenshot tool ready

Verify screenshot capability: gnome-screenshot -a or scrot -s. Some questions require proof screenshots.

10. Time management plan

6 hours / 20 questions = ~18 min per question. If stuck > 20 min, skip and move on. Mark skipped questions for review. Leave 30 min at end for review.

11. Common pitfalls to avoid

- Don't forget to URL-encode payloads for web tests
- Check both GET and POST parameters
- Try default credentials first (admin/admin, root/toor)
- Use --batch flag with sqlmap to avoid interactive prompts
- Save all evidence (screenshots, command output) before moving on
- Read the question carefully — answer format matters (IP, count, hash, etc.)

12. Post-exam cleanup

Save all notes and screenshots. Verify all 20 answers are recorded. Submit before time runs out.
