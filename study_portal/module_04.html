Exam Essentials: Enumeration

Exam Essentials

Scenario

With the development of network technologies and applications, network attacks are greatly increasing in both number and severity. Attackers continuously search for service and application vulnerabilities on networks and servers. After reconnaissance and scanning, the next step for an ethical hacker or penetration tester is to probe the target network further by performing enumeration: extracting more details about the network such as lists of computers, usernames, user groups, ports, OSes, machine names, network resources, and services. Enumeration creates an active connection and performs directed queries; it is typically conducted in an intranet environment. Enumeration activities may be illegal depending on organizational policies and local laws, so always acquire proper authorization before performing enumeration.

Objective

Extract information about the target organization including machine names, their OSes, services, and ports; network resources; usernames and user groups; lists of shares on individual hosts; policies and passwords; routing tables; audit and service settings; SNMP and FQDN details.

Overview of Enumeration

Enumeration creates an active connection with the system and performs directed queries to gain more information about the target. It extracts lists of computers, usernames, user groups, ports, OSes, machine names, network resources, and services using various techniques. Enumeration techniques are conducted in an intranet environment. The information gleaned helps identify security vulnerabilities and could enable password attacks to gain unauthorized access to information system resources.

Key Concepts

  • NetBIOS Enumeration: NetBIOS (Network Basic Input Output System) is used by Windows for file and printer sharing. A NetBIOS name is a unique 16-character ASCII name (15 characters device name + 1 service/name record type). NetBIOS runs over TCP/UDP ports 137, 138, 139. Enumeration gathers computers in a domain, shares on hosts, policies, and passwords. Tools: nbtstat, net use, NetBIOS Enumerator, Nmap NSE nbstat.nse.
  • SNMP Enumeration: SNMP (Simple Network Management Protocol) is an application-layer protocol over UDP that manages routers, hubs, and switches. SNMP agents run on networking devices. Enumeration uses community strings (default often "public") to extract user accounts, devices, ARP/routing tables, interfaces, processes, storage, filesystem, and shares. Tools: snmp-check, SoftPerfect Network Scanner, snmpwalk, Nmap SNMP NSE scripts.
  • LDAP Enumeration: LDAP (Lightweight Directory Access Protocol) accesses distributed directory services (e.g., Active Directory) over TCP 389 (LDAPS 636). Anonymous queries may leak usernames, addresses, departmental details, and server names. Tools: Active Directory Explorer, Python ldap3, ldapsearch, Nmap ldap-brute.
  • NFS Enumeration: NFS (Network File System) enables remote file access. Enumeration identifies exported directories and connected clients (IP addresses and shared data). Misconfigurations may allow IP spoofing to access shared files. NFS runs on port 2049 (RPC portmapper 111). Tools: RPCScan, SuperEnum.
  • DNS Enumeration: DNS enumeration gathers DNS server names, hostnames, machine names, usernames, IP addresses, and aliases. Techniques: zone transfer (AXFR), DNS cache snooping, DNSSEC zone walking. Runs on port 53. Tools: dig, nslookup, DNSRecon, Nmap DNS NSE scripts.
  • SMTP Enumeration: SMTP (TCP 25, 2525, or 587) enumeration obtains valid users, delivery addresses, and message recipients; also checks open relays and available commands. Tools: Nmap SMTP NSE scripts, smtp-user-enum.
  • RPC / SMB / FTP Enumeration: RPC enumeration identifies vulnerable services via portmapper; SMB enumeration enables banner grabbing (OS/services versions) and shares; FTP enumeration yields port 21 and running FTP services (bounce, brute force, sniffing). Ports: RPC 111/135, SMB 445, FTP 21. Tools: NetScanTools Pro, Nmap, Enum4linux.

Exam Tips

  • Enumeration creates active connections and directed queries; it is usually performed in an intranet environment.
  • NetBIOS name is 16 characters: 15 for device name + 1 for service/name record type; nbtstat -a shows remote name table, -c shows name cache.
  • SNMP default community string is often "public"; always identify and patch default community strings.
  • LDAP anonymous binds can leak directory objects; LDAP runs on TCP 389.
  • NFS exports may be accessible via IP spoofing if misconfigured; verify port 2049.
  • DNS zone transfers (AXFR) should be restricted; test with dig axfr and nslookup ls -d.
  • SMTP user enumeration uses VRFY/EXPN/RCPT TO; check for open relays.
  • SMB/FTP enumeration provides banners, OS versions, and shares; Enum4linux retrieves users, groups, shares, and password policies.
  • Always obtain proper authorization; enumeration may be illegal.

Lab 1: Perform NetBIOS Enumeration

NetBIOS

Scenario: NetBIOS enumeration exploits the NetBIOS API on Windows systems to collect computers in a domain, shares on hosts, policies, passwords, etc. NetBIOS uses a 16-character name (15 device + 1 service). The NetBIOS service is easy to target because it runs on Windows even when unused.

Objectives: Perform NetBIOS enumeration using Windows command-line utilities; using NetBIOS Enumerator; using an NSE script.

Task 1: Perform NetBIOS Enumeration using Windows Command-Line Utilities

Windows CMD - nbtstat, net use

What/When: Use nbtstat and net use on Windows Server 2019 (10.10.1.19) to target Windows 11 (10.10.1.11). nbtstat displays NetBIOS name tables, name cache, and protocol statistics; net use shows connections and shared resources.

Procedural steps:

# ldap-brute : brute-force LDAP authentication

# Manual LDAP enumeration with Python
python3
>>> import ldap3
>>> server = ldap3.Server('10.10.1.22', get_info=ldap3.ALL, port=389)
>>> connection = ldap3.Connection(server)
>>> connection.bind()
>>> server.info
>>> connection.search(search_base='DC=CEH,DC=com', search_filter='(&(objectclass=*))', search_scope='SUBTREE', attributes='*')
>>> connection.entries
>>> connection.search(search_base='DC=CEH,DC=com', search_filter='(&(objectclass=person))', search_scope='SUBTREE', attributes='userpassword')
