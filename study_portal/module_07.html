CEH v12 - Module 07

Malware Threats

Malware poses a major security threat to information security. Malware writers explore new attack vectors to exploit vulnerabilities in information systems, leading to sophisticated attacks such as drive-by malware, malvertising, and advanced persistent threats. This module provides first-hand experience with techniques attackers use to write and propagate malware, and teaches how to select security controls to protect information assets from malware threats. Lab tasks span Trojans, viruses, static malware analysis, and dynamic malware analysis. Ensure Windows Defender Firewall is turned off on lab machines, as it blocks and deletes malware as soon as it is executed. Labs use Windows 11 (10.10.1.11), Windows Server 2022 (10.10.1.22), Windows Server 2019 (10.10.1.19), and Windows 11 as attacker.
