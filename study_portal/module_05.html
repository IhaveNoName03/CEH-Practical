CEH v12 - Module 05

Vulnerability Analysis

Module Overview

Scenario: Footprinting and scanning already gathered target details (system name, OS, shared resources, policies/passwords, users/groups). The next step is vulnerability research and vulnerability assessment: discover, measure, and classify security weaknesses such as missing patches, unnecessary services, weak authentication/encryption, configuration errors, and known/publicly reported vulnerabilities before attackers exploit them.

Objective: Extract information about the target that includes network vulnerabilities; listening IP/TCP/UDP ports and services; application/service configuration errors; OS and application versions; accounts with weak passwords; files/folders with weak permissions; default services to remove; common application security misconfigurations; and systems exposed to known vulnerabilities.

Vulnerability databases: CWE (Common Weakness Enumeration), CVE (Common Vulnerabilities and Exposures), NVD (National Vulnerability Database), and CVSS (Common Vulnerability Scoring System). Scanning approaches: Active Scanning (probes sent) and Passive Scanning (traffic monitored).

Lab tasks: (1) Perform vulnerability research with vulnerability scoring systems and databases (CWE, CVE, NVD). (2) Perform vulnerability assessment using OpenVAS, Nessus, and Nikto.

Duration note: The lab environment shows "1 Hr 45 Min Remaining" for the module; individual scans take about 10-20 minutes.

Lab 1 - Task 3: Perform Vulnerability Research in National Vulnerability Database (NVD)

NVD (nvd.nist.gov)

What/when: The NVD is the U.S. government repository of standards-based vulnerability management data represented using SCAP. It includes security checklist references, software flaws, misconfigurations, product names, and impact metrics. Key Concepts

  • Active vs Passive Scanning: Active scanning sends probes to the target; passive scanning monitors traffic without direct interaction.
  • Vulnerability Scoring: CVSS provides standardized Base, Temporal, Environmental, and Overall severity metrics; severity ranges from None (0.0) to Critical (9.0-10.0).
  • Vulnerability Databases: CWE categorizes weaknesses; CVE provides standardized vulnerability IDs; NVD aggregates SCAP-based vulnerability data and CVSS scores.
  • Firewall Evasion/Observation: Scans may produce the same results with the firewall ON or OFF, showing that firewalling alone does not remove underlying vulnerabilities.
  • Authenticated Scanning: Providing credentials (e.g., CEH123/qwerty@123 in Nessus) yields deeper configuration and patch-level results.
  • Web Scanning: Nikto focuses on web server/application exposures such as dangerous files, outdated versions, and CGI directories.
  • Tool Comparison: OpenVAS is an open framework with 50,000+ NVTs; Nessus provides policy-based scanning and reporting; Nikto specializes in web server scanning.
