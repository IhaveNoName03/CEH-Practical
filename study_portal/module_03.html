Exam Essentials: Scanning Networks

Exam Essentials

Scenario

After footprinting/reconnaissance, the next step is port and network scanning on the IP addresses obtained earlier to identify an entry point into the target network. Scanning is an extended form of reconnaissance (not the actual intrusion): it gathers live hosts, open ports/services, OS details, and configuration lapses to build a profile of the target organization and select attack strategies.

Objective

Conduct network scanning and port scanning and analyze network vulnerabilities. Network scans are needed to: check live systems and open ports; identify services running on live systems; perform banner grabbing/OS fingerprinting; identify network vulnerabilities.

Overview of Scanning Networks

Network scanning gathers detailed target information using aggressive reconnaissance to discover exploitable communication channels, probe listeners, and track responsive ones. Types of scanning: Port Scanning (lists open ports and services), Network Scanning (lists active hosts and IP addresses), Vulnerability Scanning (shows presence of known weaknesses).

Key Concepts

  • Host Discovery: Find active/live hosts in a network (ARP, UDP, ICMP ECHO/timestamp/address-mask, TCP SYN/ACK, IP protocol ping). Reduces time vs scanning every port on every IP.
  • Port Scanning: Identify open ports and services. TCP scanning (open/stealth/half-open, Xmas, Maimon, ACK probe, connect), UDP, SCTP (INIT, COOKIE ECHO), SSDP and list scanning, IPv6.
  • OS Fingerprinting: Determine remote OS via active (crafted packets compared to DB) or passive (TTL/TCP window size, sniffing, error messages) techniques.
  • Banner Grabbing: Grab service banners/versions to identify OS and services; active or passive.
  • IDS/Firewall Evasion: Bypass security perimeters via packet fragmentation, source routing, source port manipulation, IP address decoy, IP address spoofing, custom packets, randomizing host order, bad checksums, proxy servers, anonymizers.

Tools

Nmap Hping3 Unicornscan Angry IP Scanner MegaPing Wireshark Colasoft Packet Builder (also NetScanTools Pro, sx, Metasploit).

Key Flags / Options

Flag / OptionMeaning
-snDisable port scan (host discovery only)
-sS / -sT / -sUStealth SYN / TCP connect / UDP scan
-sV / -O / -AService version / OS / aggressive detection
-f / -mtuFragment packets / set MTU size
-g / --source-portSource port manipulation
-D RND:nDecoy scan with n random decoys
--spoof-mac 0Randomize MAC address
-PnSkip host discovery
-vVerbose output

Exam Tips

  • Know the three scan types: port, network, vulnerability scanning.
  • Memorize TTL signatures: Linux/macOS 64, Windows 128, Cisco/Solaris 255.
  • Stealth scan (-sS) is half-open and can evade logging/firewalls.
  • Xmas (-sX), Maimon (-sM), ACK (-sA) scans help map firewall state (filtered vs closed).
  • Fragmentation, decoys, and source-port manipulation evade IDS/firewall.
  • Nmap -A enables OS detection, version scanning, script scanning, and traceroute.
  • Always obtain proper authorization before scanning.

Lab 1 - Task 1: Perform Host Discovery using Nmap

Nmap

What/when: Discover live hosts in the target network using various host-discovery (ping) techniques: ARP, UDP, ICMP ECHO, ICMP timestamp, ICMP address mask, TCP SYN/ACK, and IP protocol ping. Target host is Windows Server 2022 (10.10.1.22); range sweep covers 10.10.1.10-23. Run on Parrot Security after switching from the default Windows 11 machine and logging in as attacker/toor.

# ARP ping scan (local subnet) - ARP response means host is active

# UDP ping scan - UDP response (or ICMP port unreachable) means host is active
nmap -sn -PU 10.10.1.22

# ICMP ECHO ping scan - ICMP ECHO reply means host is active
nmap -sn -PE 10.10.1.22

# ICMP ECHO ping sweep across an IP range
nmap -sn -PE 10.10.1.10-23

# ICMP timestamp ping scan
nmap -sn -PP 10.10.1.22

# ICMP address mask ping scan (alternative when ECHO is blocked)
nmap -sn -PM 10.10.1.22

# TCP SYN ping scan - ACK response means host is active
nmap -sn -PS 10.10.1.22

# TCP ACK ping scan - RST response means host is active
nmap -sn -PA 10.10.1.22

# IP protocol ping scan - any response to a probe means host is active
nmap -sn -PO 10.10.1.22

# Techniques to evade IDS/firewall
Packet Fragmentation: Send fragmented probe packets
Source Routing: Specify routing path for malformed packet
Source Port Manipulation: Use common source ports (80, 53)
IP Address Decoy: Generate decoy IPs to hide real scanner
IP Address Spoofing: Change source IP
Creating Custom Packets: Craft packets to bypass
Randomizing Host Order: Scan hosts in random order
Sending Bad Checksums: Packets with bogus checksums
Proxy Servers: Chain proxies to hide source
Anonymizers: Bypass censors and evade rules

Notes: Combine multiple techniques to bypass poorly implemented defenses. Always obtain authorization.
