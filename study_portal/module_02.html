CEH v12 - Module 02

Footprinting and Reconnaissance

Reconnaissance collects information about a target, the first step in any attack. Ethical hackers and pen testers must gather enough information about the target before initiating assessments, simulating all steps an attacker follows to understand the security posture. Scope and rules of engagement (RoE) must be agreed with management first. Labs give real-time experience collecting info from open/publicly accessible sources. Target env: Windows 11 (10.10.1.11), Parrot Security (10.10.1.13), Windows Server 2019, etc. Always obtain proper authorization. Objectives: organization info (employees, addresses, contacts, partners, weblinks, web tech, patents, trademarks); network info (domains, sub-domains, network blocks, topologies, routers, firewalls, reachable IPs, Whois, DNS); system info (OS, web server OS, server location, user accounts/passwords). Footprinting is passive (no direct interaction, undetected) or active (direct interaction, target may notice).

Exam Essentials

Scenario & Objective

Scenario: Reconnaissance is the first step in any attack; ethical hackers and pen testers collect enough information about the target before assessments, simulating attacker steps. Before any assessment, discuss and define the scope with management and agree on Rules of Engagement (RoE). Then gather information from open/public sources to build a blueprint of the target's security profile.

Objective: Extract organization info (employees, addresses, contacts, partners, weblinks, web tech, patents, trademarks); network info (domains, sub-domains, network blocks, topologies, routers, firewalls, reachable IPs, Whois, DNS); system info (OS, web server OS, server location, user accounts/passwords).

Key Concepts & Definitions
  • Footprinting / Reconnaissance: Collecting information about a target network and its environment to evaluate security posture and the risk of publicly accessible information.
  • Passive Footprinting: Gathering information without direct interaction; useful when information-gathering must not be detected by the target.
  • Active Footprinting: Gathering information with direct interaction; the target may recognize the ongoing process.
  • Blueprint (footprint): The unique system profile of the target organization resulting from footprinting.
  • Scope: Identifies systems, network, policies/procedures, human resources, and any other component requiring security evaluation.
  • Rules of Engagement (RoE): The "do's and don'ts" of the assessment agreed with management.
Overview of Footprinting

Footprinting collects information about a target network/environment to evaluate security posture and the risk of publicly accessible information. It is categorized into passive footprinting (no direct interaction, undetected) and active footprinting (direct interaction, target may notice).

Key Tools & Purpose
  • Netcraft: Domain/subdomain enumeration and site reports (background, network, hosting history, OS).
  • theHarvester: Gathers emails, subdomains, hosts, employee names, open ports, banners from public sources (search engines, PGP, SHODAN).
  • Sherlock: Searches many social networking sites for a target username/person and returns profile URLs.
  • Photon: Crawls a target URL to collect in/out-of-scope URLs, params, emails, social accounts, files, secret keys, subdomains.
  • Central Ops: Free online network scanner for domains/IPs: DNS records, traceroute, nslookup, whois.
  • Shodan / Censys: Internet-wide search for publicly accessible devices, OS, ports, locations.
  • Maltego: Graph-based link analysis and transforms for DNS, WHOIS, IP, location, personal entities.
  • Recon-ng: Web reconnaissance framework with modules and DB interaction for hosts, contacts, subdomains.
  • FOCA: Extracts metadata and hidden info from documents (Office, PDF, etc.) via search engines.
  • OSINT Framework: Categorized index of OSINT tools/resources for usernames, emails, domains, IPs, social networks.
Exam Tips
  • Footprinting is the first phase; it produces a blueprint of the target.
  • Passive footprinting avoids detection; active footprinting may be noticed by the target.
  • Always define scope and agree on RoE with management before assessment; get authorization.
  • Whois queries use TCP port 43; RIRs maintain Whois databases.
  • Key info categories: Organization, Network, System.
  • Use multiple sources/tools; results may differ and change over time.
  • Tools like theHarvester use data sources (baidu, bing, google, linkedin, etc.); specify -d domain, -l limit, -b source.

Lab 4 - Perform Website Footprinting: Task 1: Gather Information About a Target Website using Ping Command Line Utility

ping (Windows)

What/when: Ping tests reachability of a host on an IP network and measures round-trip time. Sends ICMP echo request and waits for ICMP response; measures RTT and records packet loss. Assists in obtaining domain info and IP address of target website. Target here: www.certifiedhacker.com (IP 162.241.216.11). Find max frame size and TTL behavior.

# Windows 11 Command Prompt
ping www.certifiedhacker.com
ping www.certifiedhacker.com -f -l 1500
ping www.certifiedhacker.com -f -l 1300
ping www.certifiedhacker.com -f -l 1473
ping www.certifiedhacker.com -f -l 1472
ping www.certifiedhacker.com -i 3
ping www.certifiedhacker.com -i 2 -n 1
ping www.certifiedhacker.com -i 3 -n 1
ping www.certifiedhacker.com -i 4 -n 1                
Key procedural steps / narrative: Switch to Windows 11. Open Command Prompt (Search icon, type cmd). Run ping www.certifiedhacker.com to get IP address and ping stats. Run ping www.certifiedhacker.com -f -l 1500 (DF flag, buffer size 1500) to see "Packet needs to be fragmented but DF set". Run with 1300. Try 1473 (fragmented) and 1472 (success) to find max frame size (1472). For TTL: ping www.certifiedhacker.com -i 3 shows TTL expired in transit from router. Minimize and open new Command Prompt: ping www.certifiedhacker.com -i 2 -n 1, then -i 3 -n 1, then -i 4 -n 1, etc. until reply from destination 162.241.216.11; hop count here 19 (may vary).
