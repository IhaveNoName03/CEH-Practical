Hacking Wireless Networks

Wireless networking is revolutionizing the way people work and play. A wireless local area network (WLAN) is an unbounded data communication system, based on the IEEE 802.11 standard, which uses radio frequency technology to communicate with devices and obtain data. This network frees the user from complicated and multiple wired connections. With the need for a physical connection or cable removed, individuals are able to use networks in new ways, and data has become ever more portable and accessible.

Although wireless networking technology is becoming increasingly popular, because of its convenience, it has many security issues, some of which do not exist in wired networks. By nature, wirelessly transferred data packets are airborne and available to anyone with the ability to intercept and decode them. For example, several reports have demonstrated the weaknesses in the Wired Equivalent Privacy (WEP) security algorithm, specified in the 802.11x standard, which is designed to encrypt wireless data.

Scenario: As an ethical hacker or penetration tester (pen tester), you must have sound knowledge of wireless concepts, wireless encryption, and related threats in order to protect your company's wireless network from unauthorized access and attacks. You should determine critical sources, risks, or vulnerabilities associated with your organization's wireless network, and then check whether the current security system is able to protect the network against all possible attacks.

Objective: The objective of the lab is to protect the target wireless network from unauthorized access. To do so, you will perform various tasks that include, but are not limited to: Wi-Fi Packet Analysis; Crack WEP and WPA2 Wi-Fi networks.

Overview of Wireless Networking: In wireless networks, communication takes place through radio wave transmission, which usually takes place at the physical layer of the network structure. Wireless network types include: extension to a wired network (wired network extended by access points between wired network and wireless devices); multiple access points (multiple APs connect computers wirelessly); LAN-to-LAN wireless network (hardware APs interconnect with other hardware APs); 3G/4G hotspot (a mobile device shares cellular data wirelessly with Wi-Fi-enabled devices such as MP3 players, notebooks, tablets, cameras, PDAs, and netbooks).

Exam Essentials: Hacking Wireless Networks

Scenario & Objective

Scenario: Wireless networking is revolutionizing the way people work and play. A WLAN is an unbounded data communication system based on IEEE 802.11 using radio frequency technology. Because wireless data packets are airborne, they are available to anyone who can intercept and decode them. WEP (Wired Equivalent Privacy), specified in the 802.11x standard, has demonstrated weaknesses. As a pen tester you must have sound knowledge of wireless concepts, encryption, and threats to protect your company's wireless network from unauthorized access and attacks, determine critical sources/risks/vulnerabilities, and verify the current security system protects against all possible attacks.

Objective: Protect the target wireless network from unauthorized access by performing Wi-Fi packet analysis and cracking WEP and WPA2 Wi-Fi networks.

Overview of Wireless Networking & Traffic Analysis

Wireless communication occurs at the physical layer via radio waves. Network types: extension to a wired network, multiple access points, LAN-to-LAN wireless, and 3G/4G hotspots. Wireless traffic analysis determines the appropriate strategy for a successful attack. Wi-Fi protocols are unique at Layer 2, and traffic over the air is not serialized, making it easy to sniff and analyze wireless packets. You can use various Wi-Fi packet-sniffing tools to capture and analyze target network traffic, revealing broadcasted SSID, presence of multiple APs, possibility of recovering SSIDs, authentication method, and WLAN encryption algorithms. Wi-Fi attacks include: fragmentation, MAC spoofing, disassociation, deauthentication, man-in-the-middle, wireless ARP poisoning, rogue access points, evil twin, and Wi-Jacking.

Key Concepts
  • WLAN / 802.11: Wireless local area network based on IEEE 802.11; uses radio frequency; unbounded medium.
  • SSID (Service Set Identifier): The network name broadcast by the access point; identifies the wireless network.
  • BSSID: The MAC address of the access point (or client in ad-hoc); uniquely identifies an AP.
  • ESSID (Extended SSID): Same SSID shared across multiple access points in an extended service set.
  • Monitor mode: Wireless adapter mode that captures all 802.11 frames on a channel, not just those destined for the host.
  • Radiotap header: Metadata prepended to captured frames: protocol, encryption, frame length, MAC addresses, channel, signal strength.
  • 802.11 frame types: Management (beacon, probe, auth, deauth, assoc), control (RTS/CTS/ACK), and data frames.
  • WEP (Wired Equivalent Privacy): Uses RC4 stream cipher with a 24-bit IV; 40/104-bit keys; IV reuse and weak key scheduling make it crackable.
  • WPA (Wi-Fi Protected Access): Interim fix using TKIP (RC4-based) with per-packet key mixing and MIC; stronger than WEP but still legacy.
  • WPA2: Mandatory CCMP (AES-128) encryption; two modes: WPA2-Personal (PSK) and WPA2-Enterprise (802.1X/EAP); crackable via captured 4-way handshake + wordlist.
  • WPA3: Uses SAE (Simultaneous Authentication of Equals) for stronger password-based auth; forward secrecy; resistant to offline dictionary attacks.
  • WPS (Wi-Fi Protected Setup): Simplifies joining via PIN/push-button; PIN brute-force vulnerability can leak the WPA/WPA2 passphrase.
  • Rogue access point: Unauthorized AP installed on a network, not managed by the administrator.
  • Evil twin: Fraudulent AP that imitates a legitimate network name (SSID) to trick clients.
  • Deauthentication attack: Flooding station(s) with forged deauthentication frames to disconnect users from an AP.
  • Disassociation attack: Destroying connectivity between an AP and client.
  • Fragmentation attack: Obtains 1500 bytes of PRGA (pseudo random generation algorithm) from fragmented packets.
  • MAC spoofing: Changing the attacker's MAC to an authenticated user's to bypass MAC filtering.
  • Wireless ARP poisoning: Corrupting the ARP cache to associate the attacker's MAC with the target host.
  • Man-in-the-middle: Intercepting/altering traffic between two computers.
  • Wi-Jacking: Method to gain access to many wireless networks.
  • WPA handshake (4-way): Captured during client association; used for offline passphrase cracking.
  • PRGA: Pseudo random generation algorithm data recovered via fragmentation; used to forge packets.
  • Aircrack-ng suite: airmon-ng (enable monitor mode), airodump-ng (capture/handshake), aireplay-ng (inject/deauth), aircrack-ng (crack WEP/WPA/WPA2).
  • Npcap: Windows packet capture library integrated with Wireshark for WLAN traffic analysis.
  • Wordlist: Dictionary file used for WPA/WPA2 passphrase cracking (e.g., password.txt).

Key Protocols / Ports
  • IEEE 802.11 a/b/g/n/ac/ax: Wireless LAN standards (2.4 GHz, 5 GHz, 6 GHz).
  • Channels: 2.4 GHz non-overlapping channels 1, 6, 11.
  • WEP: RC4 stream cipher; 24-bit IV.
  • WPA: TKIP (RC4-based) with MIC.
  • WPA2: CCMP (AES-128) in counter mode.
  • WPA3: SAE (Dragonfly key exchange).
  • 802.1X / EAP: Enterprise authentication framework.
  • RADIUS: UDP 1812 (authentication), UDP 1813 (accounting).
  • DHCP: UDP 67 (server), UDP 68 (client).
  • ARP: Layer 2 address resolution (no port).
  • HTTP/HTTPS: Router admin interfaces on TCP 80/443.

Defenses
  • Change the default SSID before connecting the router to the access point; avoid default names.
  • Disable SSID broadcast where appropriate and do not use DHCP auto-assignment for wireless clients.
  • Use WPA2 (CCMP/AES) or WPA3 (SAE) with a strong, long passphrase; avoid WEP and WPA/TKIP.
  • Disable WPS (PIN) to prevent brute-force passphrase recovery.
  • Apply MAC filtering only as a minor layer (bypassable via MAC spoofing); not a primary defense.
  • Deploy WIDS/WIPS to detect rogue access points and evil twins.
  • Segment guest networks and restrict access to internal resources.
  • Keep firmware updated; disable remote administration; use strong admin credentials.
  • Monitor for deauthentication floods, rogue APs, and unusual handshake captures.
  • Educate users on connecting only to trusted SSIDs; verify certificate-based Enterprise auth.
Exam Tips
  • WEP uses RC4 with a 24-bit IV; IV reuse and weak key scheduling make it crackable with enough packets.
  • WPA2 handshake is captured during client association and cracked offline with a wordlist.
  • aircrack-ng: -a 2 selects WPA technique; -b specifies target BSSID; -w specifies wordlist path.
  • Lab BSSID: 20:E5:2A:E4:38:00; lab WPA2 password: password1.
  • airmon-ng enables monitor mode (airmon-ng start wlan0); airodump-ng captures traffic/handshakes.
  • aireplay-ng performs injection/deauth (aireplay-ng --deauth 0 -a <BSSID> wlan0mon).
  • Wireshark: 802.11 indicates wireless packets; Radiotap header reveals protocol, encryption, MACs, channel.
  • Monitor mode captures all frames on a channel; promiscuous mode only captures frames for the host.
  • Rogue AP is unauthorized; evil twin imitates a legitimate SSID.
  • Deauthentication floods deauth frames to disconnect clients; disassociation destroys AP-client connectivity.
  • Fragmentation attack recovers 1500 bytes of PRGA.
  • WPS PIN brute force can leak the WPA/WPA2 passphrase.
  • WPA3 uses SAE and is resistant to offline dictionary attacks.
  • Npcap is required for Wireshark WLAN capture/analysis on Windows.
  • Other analyzers: AirMagnet, SteelCentral, Omnipeek, CommView, Capsa; other crackers: Elcomsoft, Pyrit, WepAttack.
